# SPRINT 1: Recap of accomplishments made during sprint 1 of project

## Project Recap
RYTM is a website designed to help beginner musicians practice accurately reading and playing back musical rhythms. It accomplishes this by pulling a musical rhythm from a dataset, displaying it to the user, and having them play back the rhythm in time with a metronome. The website will see how far off the users input is in comparison to the note and give the user feedback.

## Worflow Demo
Currently, users can click around the website and access different menus by clicking the three primary buttons on the website page: Practice, How to Use, and Credits. These will update the website page cleanly without any refreshing necessary. Users can also view the different buttons states by hovering or focusing the buttons.
